# Sprint 02 / PR5 — Consumer Visual Shell

## Hypothesis
A user should reach Kopano-Phu media through a simple action-first surface while KC governance remains available without dominating the consumer journey.

## Bounded scope
- add READ / PLAY / WATCH / LISTEN / OWN / CREATE doors;
- make ecosystem discovery media-first using generated visual treatment only;
- preserve existing first-party surface registry and KC evaluation;
- move runtime and governance telemetry behind progressive disclosure;
- keep external adapter inspection available but secondary.

## Validation
- TypeScript 7 typecheck;
- Vite production build;
- existing .NET gateway validation remains unchanged;
- no production binary asset is claimed or redistributed by this PR.

## Non-claims
- no PR4 evidence-only binary is promoted to production;
- no commerce, creator payout, image generation, motion generation, or service-delivery backend is implemented;
- READ / PLAY / WATCH / LISTEN / OWN / CREATE are discovery doors, not claims that every downstream capability is live.

## Exit gate
`world -> media -> action -> governance when needed`
